# Hakkı Sezgin İlgü — Digital Business Card

This folder is a complete static website package for a QR-based digital business card.

Files:
- index.html — mobile landing page
- Hakki_Sezgin_Ilgu.vcf — contact card
- Hakki_Sezgin_Ilgu_CV_EN.pdf — English CV
- Hakki_Sezgin_Ilgu_CV_TR.pdf — Turkish CV

IMPORTANT:
The QR code must point to the PUBLIC URL of index.html after this folder is uploaded to a static web host.
Do not create the QR code using a local file:// URL.

Suggested deployment:
1. Upload this folder to a static hosting service.
2. Open the public HTTPS URL on a phone and test every button.
3. Use that public URL as the QR-code destination.
